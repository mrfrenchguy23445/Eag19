# Eaglercraft 1.19.4 (opensource)

A java project bringing minecraft 1.19.4 to the web via teaVM an AOT compiler used to compile java bytecode to wasm

## About the project

Development begun in late 2025 and it was an uhh... rough road very annoying things,errors and bugs alot of other stuff stopped/discouraged me but somehow singleplayer worked! it was one of the happiest moments of my life. Welp let's take a look at the project structure

## Project structure

```
 Root
   |
   |
   |---desktopRuntime(assets dir and desktop debug dir)
   |
   |---gradle(gradle wrapper)
   |
   |---jdk-shims(shims used for internal jdk mechanics)
   |
   |
   |---patcher(incomplete patcher)
   |
   |
   |---src(main sourcecode)
   |
   |---target_*(3 build projects)
   |
   |---teavm-patches (patches done to the compiler teavm)
```
