Before you click

Read this bit.

  • Use a current Chrome or Edge. JSPI is not optional.
  • The first click is deliberate. Browsers need the gesture.
  • HTTPS pages need wss://. Local ws:// is for development.
  • Protocol 764 is the preferred V5 path. 758 stays as the fallback.
  • No server patch, no proxy rewrite, no Rust bootstrap.
